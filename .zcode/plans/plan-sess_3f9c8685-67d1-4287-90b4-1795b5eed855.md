## Contexto

Remodelização completa da UI do Neothesia, executada em **colaboração com outro agente ZCode** que trabalha no mesmo workspace e vai **dirigir o trabalho** (o utilizador indicou: "ele vai te dar indicações do que fazer"). Comunicação entre os dois agentes **via documentos markdown** no workspace.

O outro agente já preparou infra de captura visual (mudanças não commitadas em curso): `neothesia/src/utils/capture.rs` — variáveis `NEOTHESIA_CAPTURE` (renderiza N frames e grava PNG), `NEOTHESIA_CAPTURE_FRAME`, `NEOTHESIA_PAGE=library|settings|tracks`, `NEOTHESIA_MOUSE=x,y` — mais alterações em `gpu.rs` e `main.rs`. Isso permite verificação visual das telas sem abrir o app manualmente.

Exploração já feita (factos-chave): UI 100% custom no toolkit `nuon` (immediate-mode → wgpu/glyphon), telas = Menu (`menu_scene/mod.rs`), Biblioteca (`library_page.rs`), Configurações (`settings.rs`), Faixas (`tracks.rs`), reprodução (`playing_scene/`), freeplay; cores hardcoded sem tema; layout manual via `translate()`; sem widgets Slider/TextInput.

## Plano

### 1. Protocolo de coordenação via documentos
Criar diretório `collab/` na raiz do repo (adicionado ao `.gitignore` para não poluir o histórico):
- `collab/DIRETRIZES.md` — **escrito pelo outro agente**: indicações de design, tarefas, prioridades. Eu leio e executo.
- `collab/PROGRESSO.md` — **escrito por mim**: estado, entregas, screenshots de verificação, perguntas/bloqueios.
- Regras de convivência no repo (registradas nos docs): anunciar ficheiros que se vai tocar antes de editar; nunca editar os docs do outro; nunca tocar nas mudanças em curso do outro agente (capture.rs, gpu.rs, main.rs, Cargo.toml).

### 2. Sincronizar com o trabalho do agente
- `cargo check` para confirmar que o build compila com as mudanças dele.
- Testar a captura: correr com `NEOTHESIA_CAPTURE` nas 3 páginas para confirmar que o canal visual funciona; reportar resultado em `PROGRESSO.md`.

### 3. Aguardar e executar as indicações do agente
- Watcher em background sobre `collab/DIRETRIZES.md` (re-invoca-me quando o agente escrever).
- A cada lote de indicações: implementar, verificar com capturas das páginas afetadas, atualizar `PROGRESSO.md` com o que foi feito + paths das imagens, e aguardar o próximo lote.
- Base de redesign já preparada (a aplicar conforme diretrizes dele): sistema de tema central no `nuon` (paleta/tipografia/raio), novos widgets (slider, input de texto real), restyling de todas as páginas, transições animadas entre páginas.
